# Type P.alpha patch and panel

`patch.json` is the voice graph and parameter manifest, and `panel.json` is the
editor control map. The generated engine in `../../firmware/gen` is built from
them, and the plugin in `../../plugin` is the product.

The design notes beside this file record the Type P.fm1 instrument that the engine
grew from. They are provenance for the sound and the panel layout.
