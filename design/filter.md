# Filter law and resonance

The filter is a four-pole ladder with a soft-clipped feedback path. The engine
keeps the ladder, because the IR3109's implicit circuit solve at 176.4 kHz does
not fit the 24-voice budget, and takes the parts that set the feel from the
reference: the exponential cutoff, the linear resonance slider, the bass
thinning and the input saturation.

## Reference

The reference is the Lemus SH-101 model at tag `ro-mono-101-v0.1.3`, files
`machines/sh101/core/filter.{h,cpp}` and
`machines/sh101/core/vcf_ir3109.{h,cpp}`. Its `docs/model-filter.md` gives the
measured behaviour:

- FREQ covers about 12 octaves. The Real unit runs from about 3.5 Hz to 14.7 kHz
  and Roland's from about 3.4 Hz to 15.6 kHz. The law is exponential below
  10 kHz and compresses above it.
- The resonance pot is a linear B taper. Self-oscillation starts at VR18 about
  0.79 to 0.82, and the feedback loop's diodes bound the amplitude.
- The ENV depth at maximum is about 7.0 to 7.65 octaves.

## Engine law

The cutoff parameter is a log position from 0 to 55296. Position 0 is 3.5 Hz
and position 55296 is 12 octaves above it, 14.336 kHz. The filter node turns the
position into the 48 kHz per-stage coefficient with the 257-entry
`p1_filter_g_q16` table in `engine/gen/math_tables.h`, interpolated between
entries. The top entry is clamped at 55296, the highest coefficient the feedback
loop takes without a parasitic oscillation, so the top pole sits at about
14.18 kHz.

The table is generated by `tools/gen_math_tables.py`. The interpolation error is
below 4 cents above 50 Hz and about 10 cents at 20 Hz. At the 3.5 Hz bottom the
relative error is larger, inaudible and below the panel's resolution.

## Resonance

The resonance parameter stays on its 0 to 41942 range and is linear. The node
derives `res_k = res / 41942 * 6.25` in Q16. The four-pole loop reaches unity at
about 79 percent of the travel, inside the reference's 0.79 to 0.82 window, and
the cubic clip on the feedback path bounds the self-oscillation.

The passband makeup `comp` is a fraction of `1 + res_k`. Its default is 0, so
the lows thin and the level falls as the resonance rises. The old default was a
full makeup, which hid the ladder's bass loss. The knob remains available as a
trim.

## Input saturation

The filter input passes through `p1_soft_clip`, `y = x - x^5/8` with `x` clamped
at full scale. The fifth-order term is 0.2 percent at -12 dBFS, 2.5 percent at
-3 dBFS and 12.5 percent at 0 dBFS. A normal level stays clean and a hot mixer
compresses like the OTA input pair. The feedback clip stays separate, so the
self-oscillation amplitude does not follow the input level.

## Envelope depth

`fenv_depth` is reinterpreted as 0 to 8 octaves, Q16 of the range. The envelope
value is doubled to Q16, scaled by the depth, multiplied by 8 and added to the
log position. The panel reads octaves, not a percentage of the old coefficient
range.

## Migration

The old cutoff was a coefficient in 0 to 55296, scaled by 60211/65536 to keep
the old 44.1 kHz cutoff in hertz. A saved value is mapped through the old
one-pole frequency and then into the new log position, so an old patch keeps its
cutoff. The preset record, the plugin state and the web library each carry a
version bump and convert on load. Host automation lanes have no version, so
their raw values shift.

## Limits

The ladder is not the IR3109 circuit. The resonance peak shape, the exact
self-oscillation spectrum and the compression above 10 kHz are approximations.
The input knee is fixed, not a drive control. The key follow still uses the
generic proportional push, so 100 percent does not track the keyboard at exactly
one octave per octave.
