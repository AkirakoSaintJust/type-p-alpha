# Bundled OFL fonts

The editor bundles three fonts as JUCE binary resources:

- `DotGothic16-Regular.ttf`, SIL Open Font License 1.1.
  Source: https://github.com/google/fonts/tree/main/ofl/dotgothic16
- `ZenDots-Regular.ttf`, SIL Open Font License 1.1.
  Source: https://github.com/google/fonts/tree/main/ofl/zendots
- `Unbounded-Regular.ttf`, SIL Open Font License 1.1, variable regular instance.
  Source: https://github.com/google/fonts/tree/main/ofl/unbounded

The licence texts are `OFL-DotGothic16.txt`, `OFL-ZenDots.txt` and
`OFL-Unbounded.txt`, so keep them with any binary distribution that contains the
font data.

The wordmark is `TYPE P.` in Zen Dots at 30px, with the dot in pink, followed by a
lowercase `a` in Unbounded Regular. Digital Desolation Plus is not bundled or used.
