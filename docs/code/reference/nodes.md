# Generator node catalogue

The local `.dev` tree is the generator library and is not part of the public
build. Each node below is a code block that the generator inlines into
`engine/gen/type_p_alpha_dsp.c`. The summary is the node's own description.

| Node | Kind | Inputs | Outputs | Summary |
| --- | --- | --- | --- | --- |
| `adsr` | node | gate | cv | Linear ADSR envelope (Q15, control rate). `gate` defaults to the patch gate (any voice sounding), so a global note-on triggers it. attack -> decay -> sustain (level) -> release. rates are Q16 one-pole coefficients, `a`/`d`/`r` advance toward the stage target, sustain holds `s`. |
| `algo` | node |  | alg | The FM algorithm selector (control rate): owns the `algorithm` param and echoes it (clamped to the 10 shipped routings) as `alg` for the audio router. |
| `amp_env` | node | gate, trigger, rate_scale, k, vk | cv | Operator amplitude envelope: a composite attack (convex warm-up to half level, concave surge to full), two directional decays, a release, and four modes. The warm-up uses `p1_ease_in` with a 0..65536 progress so the rise starts slowly and accelerates; every other segment is the one-pole, which is concave rising and convex falling. Levels are the Yamaha 0..99 scale converted through `p1_level_gain`. Rates are 0..99 with the usual key and velocity rate scaling; 0 on the warm or surge means that stage is off. `trigger` resets to the attack on a note-on edge, a gate edge starts the release, and the mode chooses sustain off, sustain on, loop1 or loop2 at the decay2 level. |
| `apc` | node | fm, width_mod | audio | Atari Punk Console (band-limited): a 555 astable drives a 555 monostable. `width` is the monostable pulse width as an absolute time (Q16 samples), so the duty is width/period and changes with pitch (the authentic cross-coupling). `fm` (audio) scales the frequency (1 + fm/32768) and `width_mod` (control) scales the width (1 + width_mod/32768), the cross-mod inputs. Both edges are band-limited with two polyBLEP corrections (like the `pulse` node), so a swept frequency stays clean. A width past the period clamps to a near-full pulse. |
| `cmul` | node | in0, in1 | cv | Control-rate multiplier: control × control → control (for control-rate modulation, e.g. envelope × tremolo LFO). The control-rate counterpart of `gain`. |
| `comb` | node | in | out | Feedback comb filter: a fractional delay line whose length is set by `cutoff` (Q16, 0..65535, the comb's fundamental is ≈ cutoff/65536 · fs/2, so it is linear in frequency up to Nyquist, and the delay is 131072/cutoff samples) with feedback (`res`), a one-pole damping lowpass in the feedback path (`tone`, 0 = dark, 32767 = bright), and a dry/wet `mix`. Global-zone filter (one shared delay line). |
| `csum` | node | in0, in1 | cv | Control-rate summer: adds its two control inputs (for summing slow modulations, e.g. vibrato + pitch envelope). |
| `ctrl_const` | node |  | out | A block-rate constant from a parameter: the value passes straight through as a control signal. It seeds an envelope start from a knob without adding a dependency edge back from the target, which would close a cycle when the target also reads the envelope. |
| `cutoff_pos` | node | k, vk | f, pos | The filter cutoff as a control signal: the cutoff parameter with the key and velocity follow applied, plus the same value as a 0 to 99 position. It feeds the filter and the filter envelope start, so the envelope does not close a cycle through the filter. |
| `dc_block` | node | in | out | One-pole DC blocker (high-pass at a few Hz): y = x - x[n-1] + r·y[n-1], removing the DC offset of an asymmetric pulse (the APC), a folded signal, or a one-sided waveform. `r` (Q15, default ~0.999) sets the pole: higher r = lower cutoff, longer settle. Cheap and stable. |
| `delay1` | node | in | out | 1-sample delay. Its register read (source) is ordered before, write (sink) after the graph, so FM feedback is exactly 1 sample. |
| `delayN` | node | in | out | Fixed-size ring-buffer delay with feedback (Q15, pool buffer). |
| `dx_env` | node | gate, trigger, rate_scale, k, vk | cv | DX-style rate/level envelope: 4 rates + 3 levels, all 0..99 (the Yamaha scale), exponential one-pole per stage (attack → decay1 → decay2 → sustain → release). Q15 gain out. The rate is a one-pole coefficient from `p1_rate_coeff[rate]` (a non-uniform Yamaha-style curve: 99 = instant ≈ 0.73 ms, 0 ≈ 7 s, ~5% finer per step at the slow end), a `rate_scale` control input (default unity) scales it, the decay 2 stage uses `p1_rate_coeff_r3` whose rate 1 is the OPM's slowest D2R, velocity → envelope rate, `k` (key-follow) and `vk` (velocity-follow) factors (Q15) push the rates toward 0 (slower) / 99 (faster). Levels are total-level 0..99 → Q15 gain via `p1_level_gain` (0.75 dB/step: 99 = max, 50 ≈ −37 dB, 0 = silence). A `trigger` event (default `voice_trig[v]`) resets to attack on every note-on edge, even mid-note (voice steal). |
| `env` | node | gate | cv | Linear attack/release envelope (Q15). `gate` defaults to the allocator's per-voice gate. |
| `fb_tap` | node | audio, k, vk, fbenv, lfo | audio | Self-feedback tap (audio rate). `level` is signed and key/velocity scaled; the signed sum of `level`, the operator feedback envelope `fbenv` and the feedback LFO `lfo` chooses the family. A non-negative sum uses the current path, and a negative sum takes the absolute value, negates it and uses the Reface-style pulse family. The level-gained output is averaged over this sample and the previous one, so the feedback follows the operator's own level and the two-tap average damps the Nyquist mode. The magnitude is clamped to 0..32767. When the magnitude is 0 the whole body is skipped, so feedback at 0 costs nothing. |
| `gain` | node | audio, cv | audio | Pure gain cell: Q15 multiply of audio × cv (no static `level`, the modulatable gain without a trim). |
| `key_bp` | node |  | bp | The key-follow breakpoint: the MIDI note (0..127) at which key scaling is neutral. Global, one key follower shared by every key_scale target. The param is passed straight through as a control signal. |
| `key_on` | node |  | on | The global key-follow switch: 1 = key follow active, 0 = off. Passed straight through as a control signal to the key_scale nodes. |
| `key_scale` | node | bp, on | k | Key-follow factor: the bipolar Q15 push factor (0 at the breakpoint, ramping to `hi`/`lo` at the keyboard extremes) from the voice's note + a breakpoint input + bipolar LO/HI percent amounts. Gated by an `on` input. Feeds a target node's `p1_key_apply`. |
| `key_scale_g` | node | bp, on | k | Key-follow factor for a global target (the filter/F-ENV): the bipolar Q15 push factor from the *highest held note* + a breakpoint input + bipolar LO/HI percent amounts. Gated by an `on` input. The one key follower. |
| `lfo` | node | trigger | cv | Low-frequency oscillator (control rate): a phase ramp driving a wave from `p1_wave` (selected by `wave`, 0 = sine). `depth` is in the target parameter's units (a signed level offset in 0..99 units for the amplitude LFO, a Q15 semitone offset for the pitch LFO). `mode` 0 is unipolar: the output starts at the target value and moves toward `depth` (a negative depth moves down). `mode` 1 is bipolar: the output is +/- `depth` around the target value, and a negative depth inverts the phase. `rate` is a Q32 phase increment per sample. `rate_fade` and `depth_fade` are 0 (off) or 1..99, with 1 the longest and 99 instant; they ramp the rate and depth from zero over the envelope rate table's 99 percent time, starting on the `trigger` edge, and reset the phase when either fade is on. |
| `liquid_filter` | node | audio, f, fenv, fenv_on | out, lp2, band, hp | A 4-pole (24 dB/oct) resonant lowpass ladder in the spirit of the Mutable Instruments Ripples / Audible Instruments Liquid Filter and the SH-101's IR3109. Four one-pole OTA stages run in series with a negative feedback whose soft clip sits on the resonance path (the Ripples OTA, and the SH-101's feedback diodes). `f` is the cutoff log position (0 to 55296 over 12 octaves, 3.5 Hz to 14.3 kHz) with the key and velocity follow already applied; `p1_filter_coeff_q16` turns it into the 48 kHz per-stage coefficient `fc`. `res` is a linear 0 to 41942 that maps to a feedback coefficient of 6.25 at the top, so the four-pole loop reaches unity at about 79 percent and self-oscillates through the last fifth. `res_k` is that coefficient. `comp` is 0 to 100 percent of the `1 + res_k` passband makeup and clamps negative to 0, the SH-101's output-side sum; 22 percent matches the reference's partial compensation. The input soft clip is `y = x - x^5/8`, so a normal level stays clean and a hot mixer compresses like the OTA input pair. `fenv` is an absolute 0 to 99 position; when `fenv_on` is 1 it replaces `f`, otherwise the cutoff is `f` exactly. The top is clamped at 55296, the highest coefficient the feedback loop takes without a parasitic oscillation. `on` bypasses. `mode` picks the output: 0 = LP4, 1 = the 2-pole band tap, 2 = the 2-pole HP (the `(1 - L)^2` tap, so its corner lines up with the LP pole). Outputs `out` (the selected mode), `lp2` (LP2), `band` (BP tap), and `hp`. |
| `lpg` | node | audio, gate | audio | Vactrol low-pass gate: one-pole LP + VCA, cutoff and gain coupled to a fast-attack/slow-decay envelope. |
| `macro` | node |  |  | The six patch macros: value, source, source range and three destinations. A control-only node, read by the offset layer rather than the audio graph. |
| `mix` | node | in0, in1 | audio | Summer: adds its two audio inputs. |
| `mix4` | node | in0, in1, in2, in3 | audio | 4-input summer (the carrier sum / matrix sum). |
| `mod_env` | node | gate, trigger, start, k, vk, scale | cv, active | Modulation envelope: three rates and levels, a release rate and level, and four modes. It starts at the `start` input, moves through l1, l2 and l3, then holds or loops by mode and releases to the release level. With `start` unconnected it starts from zero, which is the pitch and feedback offset case; with `start` wired to the target knob it is an absolute envelope. The stages use the one-pole, which is concave on a rise and convex on a fall. `trigger` resets to the attack on a note-on edge, a gate edge starts the release, and a fresh gate after that release restarts the attack. Mode 0 releases after the third level, mode 1 holds it, and modes 2 and 3 loop between the second and third levels. `active` is 1 while the envelope is on, so a target can bypass it exactly. The key and velocity factors push the effective rates. |
| `mute` | node | audio | audio | Output gate: passes the input through, or outputs 0 when `mute` is set (a per-operator mute for auditioning the algorithm). |
| `naive_apc` | node | fm, width_mod | audio | Atari Punk Console, naive (aliasing) variant: a 555 astable drives a 555 monostable. `width` is the monostable pulse width as an absolute time (Q16 samples), so the duty is width/period and changes with pitch (the authentic cross-coupling). `fm` (audio) scales the frequency (1 + fm/32768) and `width_mod` (control) scales the width (1 + width_mod/32768), the cross-mod inputs. Raw edges (no band-limiting): the aggressive, aliased APC sound. A width past the period clamps to a near-full pulse. |
| `naive_osc` | node | phase, mip | audio | Wave reader: 0 = saw, 1 = sine, 2 = triangle, 3 = square (one Q15 table `p1_naive_wave`), 4 = white noise (a self-seeded xorshift). Saw (0) and square (3) are six band-limited tables each (the top-octave anti-aliasing), the `mip` input (from the phasor's `p1_wave_mip(step)`) selects the level. The phasor's nine-level mip is mapped back to this table's six levels (level 3 and below is 0, each step above subtracts three). Sine/triangle ignore `mip`. Pulse width is *not* a shape: apply a `phase_dist` bend before this read (PWM). |
| `noise` | node |  | audio | White noise source (xorshift LFSR). |
| `one_pole` | node | audio, cut | audio | One-pole lowpass (Q15), `cutoff` sets the pole. |
| `osc` | node | phase, mip, env, lfo, morph, env_on | audio | Waveform reader: the 14-wave OPZ + OPL union (including the half square) plus the sixteen-harmonic additive bank, selected by the `waveform` param (0 = sine, 14 = spectrum). Values 0-13 read the Q15 `p1_wave` table; waves 10/11/12/13 (pulse/half square/square/saw) carry a nine-level mip map selected by the phasor's `mip`. Value 14 reads the additive bank: two sixteen-harmonic spectra per part, five mips of 256 samples, and a per-voice morph from spectrum a (morph 0) to spectrum b (morph 99), with the `env` input carrying the absolute morph position and `lfo` adding the morph LFO; `env_on` selects the envelope, otherwise the `morph` input is used. The `morph` input carries the knob as a 0 to 99 position, so the morph envelope can start there without a cycle. The bank is regenerated at the control rate when a level changes, and a 10 ms crossfade hides the update. The first voice of each control block generates the bank for both parts. |
| `phase_add` | node | phase, fm | phase | Add the FM and feedback offset after a phase map: `phase + (fm << 20)`. The shift and the wrapping uint32 add are the same integer operations the phasor used before the map was inserted, so an off map plus this node is bit-exact. |
| `phase_dist` | node | phase | phase | Classic phase distortion (Casio CZ): the VPS (d,v) inflection with v fixed at 0.5, a single bend at x=`d` distorts the phase ramp along x only. `d` = the bend position (0..1), a settable, modulatable param (wired `d_mod` + `d_depth`), clamped to (0,1). |
| `phase_env` | node |  | cv | Per-part signed phase envelope. One state per operator per part, indexed by `voice_part[v]`; every voice reads the same level. It follows the `mod_env` stages and modes but the levels are absolute percent of the breakpoint field (-100..100). A note trigger on any voice of the part restarts it, and the release starts when the part's last gate falls. The output is a control signal in percent, summed with the phase LFO and added to the phase breakpoint. |
| `phase_lfo` | node |  | cv | Per-part phase LFO. One free-running state per operator per part, indexed by `voice_part[v]`; every voice on the part reads the same value. The waveform is `p1_wave` (0..5: sine, triangle, saw, inverse saw, square, random), the depth is percent of the breakpoint field, and the existing Q31 rate/depth fades apply. The output is a control signal in percent, summed with the phase envelope and added to the phase breakpoint. |
| `phase_map` | node | phase, morph, bp, key_bp, kon, von | phase | Per-part stochastic phase map (1x). It warps the operator's pre-FM accumulator through F (one-breakpoint polyline, 1024-entry LUT) and G (1..32 linear segments on a 4096-point grid, with drift, flips and a local reorder). The geometry, LUTs, PRNG, protected mask and stochastic clocks are in one pool per operator and are indexed by `voice_part[v]`, so every voice on a part reads the same map. `on` is the bypass and is bit-exact off. The y boundaries are snapped away from the waveform's protected points and locked spans never flip or reorder; wave 14 builds a and b masks from the regenerated additive bank and combines them with the base morph. The 2x map/table read, half-band decimator and 16-sample alignment delay are not built: the graph's one-rate model cannot express the 2x path, so the shipped read stays at 1x and the aliasing limit is recorded in the contract. |
| `phase_shape` | node | phase, v | phase | Vector phaseshaping (VPS, DAFx-11, Kleimola/Lazzarini/Timoney/Välimäki): one 2-D inflection point p=(d,v) reshapes the phase ramp piecewise-linearly before the wave read. `d` = the breakpoint's x-coordinate (0..1), a settable, modulatable param (wired `d_mod` + `d_depth`), `v` = its y-coordinate (control), `v` > 1 wraps forward past the cycle (uint32, one wrap: v < 2), `v` < 0 saturates to 0. Classic phase distortion is the v=0.5 case (`phase_dist`). Both are control-rate (the slopes are block_derived). |
| `phasor` | node | mod, fm, pitch | phase, acc, mip | Q32 phase accumulator. `inc` (note-derived) is the pitch, `pitch` (control, Q15) scales it, full-scale = ±1 octave, and `detune` (cents −50..50) adds an exact per-operator offset via `p1_detune_pitch`. `fm` (audio, Q15) is scaled by 2^20 (full scale is eight cycles, the FM index), `mod` (control) is a small additive offset. `acc` is the pre-FM read phase (`state.phase + mod`); `phase` remains `acc + (fm << 20)` for existing wiring. Also outputs `mip`, the band-limited wave-table level `p1_wave_mip(step)`, so a downstream `osc` can select the table whose top harmonic sits an octave below Nyquist. |
| `pitch_env` | node | gate, trigger, k, vk | cv | Per-note pitch envelope (control rate): on/off + 4 rates (0..99) + 3 stage levels (Q15 pitch offset, bipolar) + `l4`, the level the release segment ends at. Retriggers to attack on every note-on (`trigger` = voice_trig[v]), a gate edge starts release. The one-pole uses `p1_rate_coeff[rate]`, `k` (key-follow) and `vk` (velocity-follow) factors (Q15) push the rates toward 0 (slower) / 99 (faster), the level targets are the signed Q15 levels l1..l3 and the release tail runs toward `l4`, `cv` is the pitch offset (0 when off). |
| `pulse` | node | mod, fm | audio | Band-limited pulse/square (2nd-order polyBLEP, two BLEPs, one per edge). `width` (Q15, default 0.5 = square) is the duty, the high fraction of the cycle, a settable, modulatable param (wired `width_mod` + `width_depth`), clamped to [0.01, 0.99] so the two BLEPs never collide into a narrow-pulse artifact. `inc` note-derived, `inv_inc` = 2^32/inc (note-on reciprocal). |
| `route` | node | alg, a, b, c, d | mod2, mod3, mod4, car | The 4-op FM algorithm router (audio rate): a switch over the 10 shipped algorithm routings (weights 0/1, Q15 0/32767), outputting the modulation into op2/op3/op4 + the carrier sum, specialized instead of a runtime `p1_route4` (16 multiplies + 16 table loads → a selective sum, bit-exact). The modulator outputs are ×2. The phasor scales `fm` by 2^20, so full scale is eight cycles, and the operators' −12 dB headroom quarter-scales the path, so ×2 brings a level-99 modulator to four cycles of phase deviation, the OPM's full-scale index at TL 0. The per-operator feedback bypasses the router: it taps the level gain and averages two samples, so it reaches half that index, as the OPM does. (op1 = O1 is never externally modulated.) |
| `route4` | node | a, b, c, d | audio | Routing-matrix row mixer: reads a 4-weight row of a `routing` table (by `algorithm` + `dest`) and sums the four inputs weighted 0/1. The runtime-algorithm-selection primitive. |
| `saw` | node | mod, fm | audio | Band-limited saw (2nd-order polyBLEP). `inc` note-derived, `inv_inc` = 2^32/inc (note-on reciprocal). |
| `svf` | node | audio, fenv, k, vk | low, band, high, out | Chamberlin state-variable filter with a selectable output (LP/BP/HP), a bypass, and a cutoff envelope. `f` = 2*sin(pi*fc/fs) (Q16), `q` = damping (Q16), `type` 0=LP 1=BP 2=HP picks `out`, `on` 0 = bypass (out = input), `fenv` (control, Q15) is doubled to Q16, scaled by `fenv_depth` (Q16) and added to `f`, so a note-gated envelope opens/closes the cutoff over its whole range. Bipolar `k` (key-follow) and `vk` (velocity-follow) factors (Q15) push `f` toward 0/65535 (block-derived `f_eff`). The combined cutoff `fc = clamp16(f_eff + fenv_depth·2·fenv)` is block-derived (all its inputs are block-rate), so it is computed once per block, and it is a state field, so two `svf` instances don't collide on a hardcoded local. |
| `table` | node | phase | audio | Wavetable reader: a 256-entry table indexed by the top 8 bits of `phase` (nearest-neighbor). |
| `tl` | node | audio, cv, k, vk, lfo | audio | Yamaha total-level gain: audio × cv × a 0..99 `level` mapped to a Q15 gain via `p1_level_gain` (0.75 dB/step: 99 = max, 50 ≈ −37 dB, 0 = silence), shifted `>> 2` for the −12 dB single-operator headroom (four additive carriers then sum to 0 dBFS). A block-rate `lfo` input adds a signed level offset in the same 0..99 units before the key/velocity push, so the amplitude LFO's depth is measured in level steps. Bipolar `k` (key-follow) and `vk` (velocity-follow) factors (Q15) push the level toward 0/99 (block-derived `level_eff`). When `level_eff` is 0 the operator is silent, so the two multiplies are skipped (`level_eff ? … : 0`, bit-exact). |
| `track_bp` | node | audio | audio | Note-tracked band-pass: a state-variable BP whose `f` = 2*sin(pi*f_note/fs) (note_cutoff). |
| `triangle` | node | mod, fm | audio | Band-limited triangle: a polyBLEP'd square (width 0.5) through a leaky integrator (one extra state). `inc` note-derived, `inv_inc` = 2^32/inc (note-on reciprocal), `slope` = inc/2^16 is the integration gain (block-derived), so the output is full-scale at any pitch. |
| `tuned_phasor` | node | mod, fm, pitch | phase, mip | Q32 phase accumulator with octave/semi/cent tuning. `inc` (note-derived) = note increment × 2^(octave + semi/12 + cent/1200), `octave` (−3..3), `semi` (−11..11), `cent` (−100..100). `pitch` (control, Q15) scales it ±1 octave, `fm` (audio, Q15) scaled by 2^20, so full scale is eight cycles of phase (the FM index), `mod` (control) is a small additive offset. Also outputs `mip`, the band-limited wave-table level `p1_wave_mip(step)`, for a downstream `osc`/`naive_osc`. |
| `vca` | node | audio, cv, k, vk | audio | Gain cell: Q15 multiply of audio × control cv × a `level` param (default unity). Bipolar `k` (key-follow) and `vk` (velocity-follow) factors (Q15) push the level toward 0/32767 (block-derived `level_eff`). When `level_eff` is 0 the two multiplies are skipped (`level_eff ? … : 0`, bit-exact), e.g. the fm_op self-feedback with `feedback` 0. |
| `vel_depth` | node | velocity | cv | Velocity depth (control rate): the gain `32768 - depth + velocity·depth >> 15`, `depth` is how much velocity attenuates soft notes (0 = no response, 32767 = full velocity scaling). The `velocity` input defaults to the allocator's per-voice `voice_velocity[v]` (a reserved input, q15). |
| `vel_on` | node |  | on | The global velocity-sensitivity switch: 1 = velocity follow active, 0 = off. Passed straight through as a control signal to the vel_scale nodes. |
| `vel_scale` | node | on | k | Velocity-follow factor: the bipolar Q15 push factor (0 at velocity 0, ramping to `amount` at maximum velocity) from the voice's velocity + a bipolar percent amount, gated by an `on` input (the global velocity-sensitivity switch). Feeds a target node's `p1_key_apply`. |
| `vel_scale_g` | node | on | k | Velocity-follow factor for a global target (the filter/F-ENV): the bipolar Q15 push factor from the *highest held velocity* + a bipolar percent amount, gated by an `on` input. |
| `wavefolder` | node | audio | audio | Sine wavefolder: folds the portion of the input above `threshold` (Q15) by `folds` sine folds, crossfaded by `amount` (Q15, modulatable, wired `amount_mod` + `amount_depth`). `on` 0 = dry bypass, `type` 0 = sine fold (reserved for others). |
| `dapc` | macro |  |  | Dual cross-modulated Atari Punk Console: two `apc` nodes feed each other's frequency (`fm`) and width (`width_mod`) at audio rate, so each pulse train shapes the other. `ratio1`/`ratio2` tune the two astables (note-derived Q16 ratios), `width1`/`width2` are the monostable widths (Q16 samples, absolute time), and `xf12`/`xw12`/`xf21`/`xw21` are the four cross-mod depths (Q15, unity = full). The two outputs sum through `level` and a `dc_block` removes the pulse DC. Each cross-mod path has a `delay1` breaker so the graph cycle resolves, the modulation is therefore one sample late (standard audio-rate feedback). Set the depths below unity for subtle chaos, at unity for the full aggressive DAPC. |
| `fm_op` | macro |  |  | The complete DX-style FM operator: phasor + osc(14 waveforms) + amp_env(composite attack and two decays) + tl(total-level), with per-op self-feedback (the `feedback` param: the level-gained output, averaged over two samples and delayed one sample, plus the per-op `fbenv` modulation envelope added straight to the feedback level and the signed `fblfo` feedback LFO), velocity → amplitude (`vel_amp`), velocity → FM (`vel_fm`), velocity → envelope rate (`vel_rate`), a q16 `ratio` frequency multiplier (runtime), a per-op `detune` (cents -50..50) plus the `dlfo` detune LFO on the pitch sum, a per-op amplitude LFO (tremolo) that adds its depth to the operator's total level in level units, a per-op `mute` gate, a `pitch` input (the shared vibrato LFO), per-op key-follow (level + feedback + A-ENV LO/HI) and velocity-follow (level + feedback + A-ENV amount), driven by a shared `bp` (breakpoint), `kon` (key sensitivity switch) and `von` (velocity sensitivity) input. |
| `naive_vco` | macro |  |  | Naive (non-band-limited) oscillator: tuned_phasor → phase_dist (PWM) → naive_osc. `shape` (0 = saw, 1 = sine, 2 = triangle, 3 = square), `octave` (−3..3), `semi` (−11..11), `cent` (−100..100) tune the pitch (note-derived), `width` is the phase_dist bend `d`, 0.5 (default) = no bend, anything else phase-distorts *every* shape (the classic PWM on square/pulse, a bent timbre on saw/sine/triangle), `width_mod` wires a control source into the bend. |
| `pitched_noise` | macro |  |  | Pitched noise: white noise through a note-tracked band-pass (a resonant noise pitched to the note). |
| `va_osc` | macro |  |  | Virtual analogue oscillator: tuned_phasor → phase_dist (d-only, PWM) → naive_osc. `shape` (0 = band-limited saw, 1 = sine, 2 = triangle, 3 = band-limited pulse, 4 = white noise), `octave` (−3..3), `semi` (−11..11), `cent` (−100..100) tune the pitch (note-derived), `width` is the phase_dist bend `d`, 16384 (default) = no bend, anything else phase-distorts the tonal shapes (classic PWM on the pulse, a bent timbre on saw/sine/triangle), `width_mod` wires a control source into the bend. Saw and pulse are band-limited (six levels via `mip`), noise ignores pitch. |
